# Character GIFs

Place your own transparent GIF files in this folder:

- `idle.gif` — default idle animation
- `happy.gif` — reaction when clicked
- `angry.gif` — annoyed reaction
- `dance.gif` — music reaction
- `sleeping.gif` — sleep animation

Recommended:
- Transparent background
- Similar canvas dimensions for every GIF
- Keep dimensions and file sizes modest for low-end PCs
- Avoid very high frame rates unless needed

The app currently uses a built-in CSS placeholder if `idle.gif` is missing.
Other animation files are loaded when their states are implemented.
